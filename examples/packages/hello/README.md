# Hello CodeStation Packages

This signed demonstration package installs a small command in your code-server user profile.

## Try it

After installation, open a terminal and run:

`~/.local/bin/codestation-hello`

The package uses OpenTofu's built-in `terraform_data` resource, so no public provider registry or Internet connection is required. Uninstalling the package removes the command while preserving the CodeStation Packages operation history.
