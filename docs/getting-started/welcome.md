# Welcome to CodeStation

CodeStation brings together the information and tools you need for your development environment.

## Container resources

The status bar displays three compact metrics:

- CPU usage as a percentage of the container quota;
- remaining memory;
- remaining disk space under `/home/coder`.

Hover over any metric to display full details. Select it to refresh the measurements immediately.

## Internal documentation

Markdown documents shipped in the extension's `docs` directory are grouped by folder and indexed automatically. Use the search field to filter documents by title, summary, path, or category.
