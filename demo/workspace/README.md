# CodeStation Packages Demo

Welcome to the complete CodeStation Packages demonstration.

1. Select the **CodeStation Packages** cube in the Activity Bar.
2. Open **Hello CodeStation Packages**.
3. Select **Install** and watch the live OpenTofu installation window.
4. Open a terminal and run `~/.local/bin/codestation-hello`.
5. Return to the package page and select **Uninstall**.

The runtime network is isolated from the Internet. Catalogue metadata and package objects are stored on the registry's local persistent volume, and the extension reaches the registry directly over internal HTTP.
